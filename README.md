# NewBitX 官网（MVP）

域名：`www.newbitx.com`

## 定位（诚实版）

| 模块 | 现在做什么 | 以后做什么 |
|------|------------|------------|
| BD 学院 | 北美向 4 周训练路径与能力说明 | 课程视频、作业批改、学员案例 |
| KOL 名录 | 精选公开快照 + 北美标签筛选 | CRM、商务认领、撮合试单 |
| 交易所目录 | 公开 Affiliate 口径分层（可推 / 教材） | 仅签约后显示「官方伙伴」 |
| 加入 | mailto 意向收集 | 正式表单 + 审核流 |

**不要**在未签约时宣称「已关联所有大型交易所」。本站用「公开目录」与「官方伙伴」两级诚实表达。
